# Tab Unloader

Расширение для Chrome / ChromeOS. Когда свободной оперативной памяти становится меньше порога,
оно выгружает вкладки, в которых вы дольше всего не были. Вкладка остаётся на месте и
перезагружается, когда вы на неё переключаетесь.

Выгрузка срабатывает раньше, чем система начнёт сжимать память в своп (zram), поэтому
Chromebook меньше подвисает.

## Что не выгружается

- активная вкладка в каждом окне;
- вкладки, где играет звук;
- закреплённые вкладки (можно отключить в настройках);
- вкладки, открытые за последние N минут (по умолчанию 10);
- сайты из белого списка (например, `music.youtube.com`, `mail.google.com`);
- служебные страницы (`chrome://…`, страницы расширений).

Если на странице есть несохранённый текст в форме, он пропадёт при выгрузке. Такие сайты
лучше добавить в белый список.

## Установка

1. На GitHub выберите эту ветку → **Code** → **Download ZIP**.
2. В приложении «Файлы» откройте архив и **скопируйте** папку `tab-unloader` в «Мои файлы».
   Из самого архива загружать нельзя: после его закрытия расширение пропадёт.
3. Откройте `chrome://extensions`, включите переключатель «Режим разработчика» в правом
   верхнем углу. Это переключатель только для страницы расширений, режим разработчика
   ChromeOS он не включает и ничего не стирает.
4. Нажмите «Загрузить распакованное расширение» и выберите папку `tab-unloader`.
5. Закрепите значок расширения на панели (иконка пазла → булавка).

## Как пользоваться

На значке показано, сколько свободно памяти в ГБ. Серый фон — всё в порядке, красный —
памяти меньше порога, расширение выгружает вкладки (до 3 за проверку, проверка раз в 30 секунд).

В окне расширения:

- **Выгрузить фоновые вкладки сейчас** — выгружает сразу все подходящие вкладки, даже недавние;
- **Выгружать, когда свободно меньше (МБ)** — порог. Если вкладки выгружаются слишком часто,
  уменьшите его; если ноутбук всё ещё подвисает, увеличьте;
- остальные настройки сохраняются сразу при изменении.
